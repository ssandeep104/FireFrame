# FireFrame project guidance

## Adding wallpapers

- When the user provides an image to add as a FireFrame wallpaper, adjust the image itself so the upper-left weather area and upper-right clock/date area remain attractive and readable with white text. At 1920 x 1080, inspect roughly x=0-450, y=0-320 on the left and x=1450-1920, y=0-260 on the right.
- Subdue pale or white gradients and strong highlights in those areas. Use darker colors and restrained texture that fit the image, with soft transitions into the rest of the artwork. Preserve the main subject, the center, and the overall visual identity.
- Keep an untouched copy of the supplied image. Prepare the in-app wallpaper as a 1920 x 1080 JPEG without distorting the image.
- Preview the result with FireFrame's weather, time, date, and top-right icons. If a Firestick is available, inspect a TV screenshot after installation and refine any remaining text collisions before calling the wallpaper finished.
- Apply this rule only to FireFrame wallpaper work. Follow any more specific visual direction the user gives for an individual image.
